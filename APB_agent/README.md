### AHB Agent – UVM Verification

This module implements an **AHB UVM Agent** for generating and monitoring AHB transactions in the AHB-to-APB Bridge verification environment. It consists of a transaction class (`ahb_xtn`) with constrained-random generation of addresses, transfer sizes, burst types, and read/write operations, along with a sequencer, driver, and monitor. The sequences generate single and burst AHB transfers, including incrementing and wrapping address patterns. The driver converts sequence items into AHB bus transactions through a virtual interface, while the monitor observes bus activity, collects read and write transaction details, and publishes them through a UVM analysis port. The agent configuration supports active and passive modes, and the agent top module handles the creation and configuration of multiple AHB agents within the verification environment.
