### AHB-to-APB Bridge – UVM Environment

These files bring together the main components of the AHB-to-APB Bridge verification environment. The environment configuration controls which agents, virtual sequencer, and scoreboard are created, while the environment connects the AHB and APB agents to the virtual sequencer and scoreboard. The virtual sequencer and virtual sequences coordinate the AHB single and burst transactions, and the scoreboard compares the data and addresses observed on the AHB and APB interfaces while collecting functional coverage. The `top.sv` module connects the bridge RTL to the AHB and APB interfaces, generates the clock, sets the virtual interfaces through the UVM configuration database, and starts the test. Together, these files provide the structure needed to run and check AHB-to-APB bridge verification tests.
